ฐานข้อมูล: supetcenter_web_app
ที่วางไฟล์ PHP: /volume1/web/supetcenter/php/
เข้าผ่าน: http://192.168.1.108:8080/php/api.php

----------------------------------------------------
 ลำดับการติดตั้ง (ทำตามนี้)
----------------------------------------------------

[ถ้าเพิ่งเริ่มจากศูนย์]
1. รัน schema.sql ใน phpMyAdmin (สร้างฐานข้อมูล + 15 ตาราง)
2. แก้รหัสใน create_user.sql (CHANGE_THIS_PASSWORD) แล้วรัน (สร้าง user)
3. รัน export_sql.gs ใน Apps Script -> ได้ไฟล์ SQL -> import เข้า phpMyAdmin
4. รัน schema_patch.sql (แก้คอลัมน์วันที่ + ตาราง login_fail)

[ถ้าติดตั้งบางส่วนไปแล้ว - ทำเฉพาะที่ยังไม่ได้]
- ยังไม่ได้แก้วันที่/ล็อกรหัส -> รัน schema_patch.sql
- อัปโหลดโฟลเดอร์ php/ ทั้งหมดทับของเดิม

----------------------------------------------------
 ตั้งค่า config.php (สำคัญ)
----------------------------------------------------
เปิด php/config.php แก้ให้ตรงกับเครื่องคุณ:
  db_host = 'localhost'
  db_port = 3306
  db_pass = 'รหัสที่ตั้งใน create_user.sql'
